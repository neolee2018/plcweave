# 硬件约束与挂起项 V002

- 型号：用户明确指定 HBDTECH L01S-16M-4AD2DA，4AI/2AO。
- 当前现场：用户确认空机，无传感器和执行设备；本轮不改变现场接线。
- AI0：D8030；AI1..3：D8031..D8033（不用作控制）。
- AO0：D8050；AO1：D8051（恒0）；原始范围0..4000。
- 依据：既有私有手册提取件 reference/l01s_user_manual.md 的模拟量输入、
  模拟量输出和§8.2.4通信章节。来源清单/哈希在evidence/reference-provenance.json。
  这些厂家资料仅作私有参考，不复制进公开仓库或交付包。
- 订货电气类型、端子实物和输出晶体管/继电器细分未核实；本轮仅做寄存器
  逻辑演示，物理接线及实际0..10V或4..20mA验证挂起，不能推定端子电气精度。
- Y0仅代表运行允许输出；用户未接负载。本例没有伺服轴、变频器通讯或硬接线急停。
- COM5编程协议9600/7E1；COM7 Modbus RTU站1,9600/8N1。
- 特殊串口参数：M8196/M8125=1,D8120=HE081,D8121=1。
  旧采集样例H0E81与手册冲突，继续使用手册组合，仍需本版本通信实证。
- CPU STOP会使既有样机Modbus不可用；若后续执行初始化实测，控制/恢复须走COM5。
- S5原厂编译及仿真按用户禁止GX要求不执行；本地指令子集不能替代原厂门禁。
- G1：所有影响本轮寄存器逻辑的接口已有书面规格；实际电气/带载/掉电保持
  明确挂起，不得将寄存器采样升级为完整硬件验收。
