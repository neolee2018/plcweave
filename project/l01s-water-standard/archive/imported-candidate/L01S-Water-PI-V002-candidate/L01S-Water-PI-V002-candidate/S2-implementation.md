## Algorithm and allocation

First-scan defaults clear run/states/timers and disable physical routing, validate saved SV, initialize serial image and build identity. Every scan clamps the active SV and selected signed raw ADC before scaling. Only exact mode 0/1 is valid; invalid mode clears run and sets restart inhibit. Only a zero start request observed in a valid mode releases the inhibit; a later one starts. Stop is applied after start, therefore wins.

T1 performs continuous 3 s wake qualification, then T0 performs continuous 5 s pre-sleep qualification. Each false timer rung resets elapsed time. Wake can enter pre-sleep immediately at overlapping minimum-setpoint thresholds. Final M10 means pre-sleep and M11 means sleep. All final output mapping occurs after state transitions.

M20 snapshots normal state before current-scan state transitions; M21 is final normal state. PI executes only when both are true and an unconditional current/previous M8012 comparison produces M2. Thus entry to normal always outputs 2000 with zero integral and skips PI on that scan, including a coincident clock edge. The next eligible rising edge performs signed integer recurrence and clamps. MUL/DIV destination pairs have exclusive allocation: D112/113, D114/115, D116/117, D122/123, D124/125, D130/131, D132/133. All division inputs used for pressure, threshold, integral and AO quotient are nonnegative; PI signed error multiplication fits 16-bit low word. Maximum integral intermediate 30160 and maximum AO product 20000 cannot overflow signed16.

Instruction set after static diagnosis: LD, LDI, AND, ANI, OR, comparisons AND=/AND</AND>/AND<=/AND>=, OUT, SET, RST, MOV, ADD, SUB, MUL, DIV with nonzero positive constant divisor, END; T0/T1 use 100 ms base. No private PID, floating point or downloader is used. Global edge is formed from current M8012 and previous-scan M3; M3 is initialized false and updated unconditionally after M2. The new source is compiled against the actual supported engine, not accepted by self-reading.
