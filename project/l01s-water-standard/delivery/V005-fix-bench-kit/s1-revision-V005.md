- V005 首版 §05 组合位 `OR Mx / OUT Mx` 自锁结构在真机 FX 扫描语义下永久锁存：
  停止释放后组合启动位仍为 1 → 自启动（实机 STD-059/062 等 M0=1 实证）。
  gxwlib 仿真器不自锁 → SIM 未复现——**仿真 ≠ 真机的又一实证**。
- 修复：删除自锁组合位，改为每源独立梯级直接 SET/RST M0（LD M1 / ANI M12 /
  AND= Dx K1 / SET M0；停止梯级 RST M0 后置）。全部为已验证指令形式。
