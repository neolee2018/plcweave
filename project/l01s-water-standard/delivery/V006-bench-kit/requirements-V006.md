## 修订条款

### R06 (V006 wake pressure) — 唤醒压力首扫固定 4.0 bar

唤醒压力 W 是独立可设寄存器 D326（0.1 bar）。**首次扫描固定写入 D326=40（4.0 bar）**，
不再按"保存设定×85%"计算；原 V005 的 `MUL D325 K85 / DIV K100` 首扫梯级删除，
D167/D168 自 V006 起不再使用。此后 D326 仍为外部写入优先，程序每扫描不再覆盖；
在线比较使用 `clamp(D326,0,160)` → D160。

影响：唤醒门槛由 V005 的 5.1 bar（SV=60 时）降到 4.0 bar → 更容易唤醒、更晚进入休眠。

### R09 (V006 first scan) — 首扫默认值增量

除 V005 已有的 D322=1、D320/D321/D323=0、D327=100、D328=30、D329=2000、D334/D335=0 外，
V006 增加：

| 寄存器 | 首扫值 | 含义 |
|---|---|---|
| D326 | 40 | 唤醒压力 4.0 bar（见 R06） |
| D336 | 80 | 最大压力 8.0 bar（见 R15） |
| M40 | 0（RST） | 超压锁存清零 |

D300=6（版本字）、D304=6（套件字）；D301=31（版次字本轮不变）。

### R12 (V006 status block) — D300–D319 含义增量

- D307 状态位图：bit0 运行 / bit1 休眠 / bit2 休眠计时 / bit3 唤醒计时 / bit4 测试 /
  bit5 使能 / **bit6 PV 卡满量程诊断（V006 新增，见 N1C）** / **bit7 超压封锁（V006 新增）**。
  每扫描先清零再按位叠加，最大组合 255，无溢出。
- **D316 由"保留恒 0"改为 `最大压力生效值` 镜像（D175，0.1 bar）**。
- 其余 D300–D319 与 V005 一致（D305 心跳、D306 扫描计数、D308–D315 镜像、D317 回显、
  D318 选中原始码、D319 PI 积分）。

### R13 (V006 command block) — D320–D336 共 17 字

命令块由 V005 的 16 字扩展为 **17 字**，新增：

| 寄存器 | 权限 | 单位 | 范围 | 首扫 | 含义 |
|---|---|---|---|---|---|
| D336 | RW | 0.1 bar | 10..160 | 80 | 最大压力设定；在线钳位入 D175 |

其余 16 字（D320–D335）语义不变。D326 首扫值改为 40（R06）。

### R14 (V006 refresh contract) — 一轮刷新 = 37 字读 + 17 字写

- 读：一条 FC03 读 **D300–D336**（37 字）。
- 写：一条 FC16 从 D320 写 **17 字**（D320–D336）。
- 复位/中性帧同样为 17 字，其中 D326=40、D336=80（避免复位瞬间把上限写成 0 而误锁输出）。
- D300–D336 之外不构成 HMI 写授权。

### R15 (V006 overpressure protection) — 最大压力保护（新增）

**阈值**：D336（0.1 bar）每扫描钳位到 [10,160] 得生效值 D175；回差阈值 D176 = D175−5（0.5 bar）。

**触发**：运行中（M0=1）且实际压力 **D100 > D175**（严格大于，等于不触发）→ 置锁存 M40。

**封锁**（PI 之后、物理输出之前覆盖）：
- D154（频率）= 0 → Y0=0；
- D120（PI 积分）= 0（锁存期间每个扫描都清零，解锁后从 K2000 地板重新爬升）；
- 因此 D8050=0、D311=0。

**报警**：D307 bit7 置位（值 128），随 M40 同步；界面以红字提示。

**自动恢复**：`D100 <= D176`（上限−0.5 bar）→ 清 M40，封锁立即解除；若启动请求仍在
（M0=1）则从 2000 地板重新出力。停机不清锁存，压力回落后同样自动清除（无需人工复位）。

**判定输入**：实际压力 D100（= clamp(D110,0,4000)+12)/25，0.1 bar），与显示/镜像 D308 同源。

**边界**：
- 恰好等于上限（D100 == D175）不触发；
- 触发后即使回落到上限与回差之间（D176 < D100 <= D175）仍保持封锁；
- D336 越界（<10 或 >160）钳位后生效，D316 显示钳位后的值。
