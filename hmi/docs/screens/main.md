## 组件清单

- **顶栏**：COM 下拉 + 刷新、波特率下拉（600–115200 九档）、数据格式下拉（8N1/8N2/8E1/8O1/8E2/8O2）、从机地址输入（1–247）、版本地址输入（Dn）、连接/断开按钮、程序版本显示、状态徽章。
- **数字输入卡**：X0–X7 横向单排按钮（保持开关/按住有效两种交互）、每点下方独立状态小灯 + ON/OFF/未知/待确认文字、交互模式下拉、硬件原值折叠区（FC02 X0–X7 原值）。
- **模拟输入卡**：AD0–AD3 四列；每列 = 通道名、量程下拉（0–10V/0–20mA）、竖直只读滑条（−/＋ 在左右）、工程值 + 目标/生效行、数值输入框 + 应用按钮、就地错误标签。
- **数字输出卡**：Y0–Y7 只读点位牌（Label，非按钮）+ 每点独立小灯（FC01 直接读 Y）。
- **模拟输出卡**：DA1–DA2 两列只读（FC03 直接读 D8050/D8051）；量程下拉、竖直滑条、工程值 + `raw N · 手册 DA0/D8050` 注记。
- **仿真操作栏**：开始仿真/结束仿真（同一按钮随状态切换）、应用全部、复位仿真输入、导出本次日志、最近30次调试记录、版本与接口设置、步长下拉（1%–10%）。
- **客户寄存器区**默认显示在四象限下方。监控表格在上；添加行（监控地址 + 名称 + **权限下拉：只读/只写/读写**）、移除选中、**导入CSV**、**导出CSV** 在中（按钮经 Customer.TButton 样式与输入框等高）；发送地址（仅权限含"写"的条目）、整数值、发送在下。
  - **权限语义（V0.4.2）**：只读=仅监控轮询显示；只写=仅允许发送命令、不轮询读取（状态列标"只写·不轮询"）；读写=既读又可发。每条目独立设置，随界面配置持久化。
  - **发送规则**：发送地址下拉只列出权限含"写"的监控条目；发送范围取 接口档案声明范围 与 条目自带范围（CSV 可给） 的交集，两者都缺省为 0–65535 原始值。硬件观察点与接口档案地址（D8030–33/D8050–51、会话/版本寄存器等）受保护：显示"只读"，任何情况下不经客户通道写入。只写条目发送后如实标注"已发送（不读回）"，不虚构读回值。
  - **CSV 导入**：列 = `地址,名称,权限[,最小值,最大值]`；首行表头自动跳过；权限支持 只读/只写/读写 及 RO/WO/RW 别名；范围可选（0–65535 原始值）。逐行校验，非法行跳过并在状态栏显示行号与原因，成功/部分成功/失败均入操作日志；上限 32 条。
- **日志区**：本次操作日志表（时间|操作对象|目标值/生效值|结果）+ 数据年龄/刷新耗时/状态行。
- **运行测试脚本**：位于日志/客户寄存器切换按钮旁；打开文件与参数对话框。实机默认选择 `l01s-water-standard/run_hil_v3.py`，演示可载入内置脚本。待确认时按钮变“确认测试结束”，可重新打开结束提示。

## 变量绑定

绑定关系逐项对应 [params.md](../../params.md)：

| 界面元素 | 数据来源 | 更新时机 |
| --- | --- | --- |
| X 小灯 | 接口档案生效镜像（PLC→PC 读回），非按钮目标值 | 每次组确认后 + 轮询 |
| X 按钮底色 | 本机目标值（待应用样式） | 用户操作即时 |
| Y 小灯/点位牌 | FC01 @ 0x3300 直接读取 | 每轮询 |
| AD 滑条 | 接口档案 AD 生效镜像 raw/4000 | 每次组确认后 + 轮询 |
| AD 目标/生效文字 | 本机目标（工程换算）/ PLC 生效镜像 | 即时 / 轮询 |
| DA 滑条与数值 | FC03 @ D8050/D8051 直接读取 | 每轮询 |
| 客户寄存器监控 | 所选 D 单字经 FC03 直接读取（仅权限含"读"的条目轮询） | 连接后的轮询与发送后读回 |
| 客户寄存器权限列 | 条目权限（本机配置）+ 档案声明/条目范围交集 | 添加/导入/选中即更新 |
| 程序版本 | 用户配置 Dn，FC03 单字 | 连接成功时；断开即清空不缓存 |
| 硬件原值 | FC02 @ 0x3400、FC03 @ D8030–33 | 每轮询（仅诊断） |
| 脚本命令/输出 | 子进程通讯请求/响应，stdout/stderr、原始 serial 字节 | 实际发生后经队列显示；原始意图先落盘再发送 |
| 脚本中 PLC 状态 | 该脚本实际读取的地址与值；Y 为 FC01，DA 为 D8050/51 | 响应成功才更新，未读到的点位未知 |
| 压力工程 AD0 手动输入 | D1056 注入 / D110 已选输入；需 D190=1 | 写前身份与模式检查，随后实际读回 |

## 交互流程

1. **连接**：填 COM/波特率/格式/站号/版本地址 → 连接。设置校验失败就地弹窗；成功显示版本并只读刷新；失败显示原因回到未连接。
2. **开始仿真**：未连接时一键自动连接 → 建 session 记录 → 预检（档案完整 + confirmed）→ 会话握手 → 提交初始输入组 → 等消费确认 → 状态“仿真中”。任一步失败记录“启动失败”并退出，不开放注入。实机模式开始前弹出台架确认对话框。
3. **输入**：X 点击/按住提交目标；AD ＋/−（步长=满量程百分比，边界钳位）或数值框输入（非法就地报错不发送）；应用全部/复位整组提交；一次只允许一组在途，被拒绝的操作入日志。
4. **结束仿真**：发送结束请求 → 等结束确认与结束态（上限 5s）→ 读回输出 → 回到“已连接·未仿真”。超时标“结束未确认”并释放串口。
5. **客户寄存器**。直接在底部添加监控并选权限（只读/只写/读写），或点"导入CSV"批量导入。仿真中从发送地址下拉（仅权限含"写"的条目）选择地址，输入整数，点发送：读写条目显示读回值，只写条目标注"已发送（不读回）"。点击"查看操作日志"查看写入与结果。
6. **导出**：仿真中导出当前快照（会话不中断）；记录页可导出历史 ZIP（summary.json + operations.csv + samples.csv），同名不覆盖。
7. **脚本**：运行测试脚本 → GUI 自身释放连接和轮询 → 显示实际通讯及状态 → 原脚本结束并完成本次进程树/连接清理 → “测试完毕”弹窗。正常和异常退出都提示；明确确定后再连接原成功通讯目标，开启新手动记录。实机压力工程核对五字身份，AD0 和客户寄存器按项目点表开放，其余无映射输入禁用。原脚本保持原报告格式及用例判定。

## 场景变体（状态 → 界面表现）

- **未连接**：小灯“未知”、数值“—”、竖条空轨道；可编辑待应用值（不发送）。
- **已连接·未仿真**：显示实际版本；Y/DA 只读刷新；注入按钮禁用。
- **仿真中**：X/AD 可操作；小灯/竖条只随 PLC 确认值更新；数据年龄实时显示。
- **待确认**：目标值独立显示；按钮目标样式与小灯分离，不提前亮灯。
- **故障/断线**：值标“过期”（橙色）+ 版本标“失效”；禁止发送，需重连。
- **进行中会话**：日志区持续滚动；导出按钮可用；结束按钮切换。
- **脚本测试中**：连接、输入、发送及重复运行禁用，日志可查看和导出；输入设定框跟随脚本目标，状态灯和滑条跟随真实读值。
- **测试完毕·待确认**：脚本及受控后代已退出，无 GUI 串口连接；确认按钮可用，其他发送禁用。
- **实机手动测试**：原脚本连接目标只读重新核对版本和构建身份后，开放已知输入和客户寄存器发送；不使用演示 D8100 系列会话地址。用户主动关闭，手动退出不发送原脚本未定义的结束命令。
