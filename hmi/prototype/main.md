数字点位在最小受支持窗口和缩放下仍各为一整排；X0与Y0、X1与Y1依次上下对齐。每个点位牌下方固定一颗小灯，其下附ON/OFF/未知/过期文字，不把按钮背景颜色当作唯一状态提示。输出点位牌只是只读显示，不新增强制输出操作。

## 组件与绑定

| 组件 | 绑定 | 交互 |
| --- | --- | --- |
| 连接设置 | 本机COM、波特率、数据格式、目标站号 | 连接期间锁定；站号1–247，不改PLC站号 |
| 版本地址/显示 | 用户配置Dn，FC03只读 | 连接后显示实际应用版本数；无通用预设地址 |
| 开始仿真 | 连接+版本读取+输入接口预检+会话 | 未连接可一键开始，点击即创建本次记录 |
| X横排按钮 | 输入暂存 | 保持/按住；目标样式与下方生效灯分离 |
| X按钮下方小灯 | PLC已确认输入镜像 | 生效后更新，未知/过期有独立文字样式 |
| AD竖直滑条 | PLC已确认生效AD | 4列并排，上满下0；数值在下，所有拖动调节禁用 |
| AD左右加减/下方数值框 | 工程量程→输入档案raw | 默认步长满量程5%，可调1%–10% |
| AD类型 | 本机每路0–10V/0–20mA | 保持raw，不发写入，日志记录变更 |
| Y横排点位牌及下方灯 | FC01直接读Y0–Y7 | 8点只读，灯在牌下，不读替代镜像、不允许强制 |
| DA竖直滑条及下方读数 | FC03直接读D8050/D8051 | 2列并排，每路可换V/mA显示；无加减或写入 |
| 结束仿真 | 输入会话结束请求及PLC确认 | 禁止新输入；记录清理；结束后保持只读连接 |
| 本次日志/历史 | 会话及逐操作记录 | 自动保存，最近30次已结束+当前记录，可导出 |

## 状态变体

- **未连接**：小灯未知、实际数值“—”，竖条显示未知样式，不能暗示已取到0。
- **已连接·未仿真**：显示实际版本及Y/DA；输入待应用值不等于已生效值。
- **仿真中**：X/AD可操作；小灯与竖条只随PLC确认/读取结果更新。
- **待确认**：目标值独立显示，X灯和AD竖条不提前跳到目标。
- **过期/断线**：小灯有过期样式及文字；竖条保留最后值并标明时间，不当作当前值。
- **结束/历史**：继续使用V0.2的结束确认、30次轮转及全操作记录规则。
