## 组件与绑定

| 组件 | 绑定 | 交互 |
| --- | --- | --- |
| 连接设置 | 本机COM、波特率、数据格式、目标站号 | 连接期间锁定；站号1–247，不改PLC站号 |
| 版本地址/显示 | 用户配置Dn，FC03只读 | 连接后显示实际应用版本数；无通用预设地址 |
| 开始仿真 | 连接+版本读取+输入接口预检+会话 | 未连接可一键开始，点击即创建本次记录 |
| X卡片 | 输入暂存与生效镜像 | 保持/按住；等待PLC确认，非硬件X写入 |
| AD加减/数值框 | 工程量程→输入档案raw | 点击提交，步长默认满量程5%、可调1%–10% |
| AD滑条 | PLC已确认生效AD | 展示位置；所有鼠标/键盘/触摸调节均禁用 |
| AD类型 | 本机每路0–10V/0–20mA | 保持raw，不发写入，日志记录变更 |
| Y灯 | FC01直接读Y0–Y7 | 单组只读，不读替代逻辑镜像 |
| DA数值/量程条 | FC03直接读D8050/D8051 | 每路可换V/mA显示；无加减或写入 |
| 结束仿真 | 输入会话结束请求及PLC确认 | 禁止新输入；记录清理；结束后保持只读连接 |
| 本次日志/历史 | 会话及逐操作记录 | 自动保存，最近30次已结束+当前记录，可导出 |

## 状态变体

- **未连接**：实际值“—”；可设参数或待应用值，点击开始会连接。
- **已连接·未仿真**：显示所读应用版本和实际Y/DA；输入修改不发送。
- **启动中**：本次记录已开始；显示连接、读版本、预检、会话阶段。
- **仿真中**：X/AD可操作，Y/DA始终直接读取；滑条不接受拖动。
- **待确认**：目标值与生效值分开，滑条仍显示最近已确认值。
- **结束中/结束未确认**：禁止新命令，日志持续记录清理与真实结果。
- **过期/断线**：保留最后值与时间并标灰；不显示为0，不重放旧操作。
- **历史详情**：显示会话状态、版本、格式、量程/步长及全操作时间线。
