### 2.1 已实现建议分配（proposal，实机前必须逐项核对）

V0.3 软件已实现（2026-11-04），内置演示档案给出下表建议分配，**仅回环演示后端与自动化测试使用**；实机模式在档案 confirmed=false 时拒绝写入（自动化测试守护）。实机前须与目标 PLC 程序逐项核对后另存档案并置 confirmed=true。

| 用途 | 寄存器 | 方向 |
| --- | --- | --- |
| 会话申请 / 确认 / 状态 | D8100 / D8101 / D8102 | PC→PLC / PLC→PC / PLC→PC |
| 主机心跳 / PLC存活 | D8103 / D8104 | PC→PLC / PLC→PC |
| 提交序号 / 内容校验 / 消费序号 | D8105 / D8106 / D8107 | PC→PLC / PC→PLC / PLC→PC |
| 结束请求 / 结束确认 | D8108 / D8109 | PC→PLC / PLC→PC |
| X0–X7 暂存 | D8110–D8117 | PC→PLC |
| AD0–AD3 暂存（raw） | D8118–D8121 | PC→PLC |
| X0–X7 生效镜像 | D8130–D8137 | PLC→PC |
| AD0–AD3 生效镜像（raw） | D8140–D8143 | PLC→PC |

组提交语义：PC 依次写暂存（FC16）、内容校验和（16 位累加和 &0xFFFF）、提交序号（最后写）；PLC 校验通过后整组消费并回写消费序号与生效镜像。演示后端的演示程序实际驱动 Y0=生效X0、Y1=生效X1、Y2=X0与X1、Y3=生效AD0>2000、DA1=生效AD0、DA2=生效AD1；结束/心跳超时由 PLC 侧清零输出（PRD §8.3）。

数据格式拆解：8N2为8数据位、None校验、2停止位；其余格式依此映射。首版RTU不用7位格式。所选参数必须与已下载的PLC程序匹配；上位机不写D8120/D8121/M8196/M8125，也不因为能配置就声称全部组合已实测。

通讯初始化由PLC程序负责。手册§8.2.4示例为M8196=1、M8125=1、D8120=HE081、D8121=H1（9600/8N1/站号1）；历史案例也有H0E81记法，新构建须按位定义、工具编码和实机核对，不随意忽略高位差异。站号和格式下拉仅配置电脑端。
