# PLCWeave 手动HIL仿真台设计资料

- [PRD.md](PRD.md)：产品与界面需求V0.1，待用户审核，是本轮主交付。
- [params.md](params.md)：硬件寄存器依据、软件变量和未分配接口边界。
- [prototype/main.md](prototype/main.md)：静态文字线框，非可运行原型或软件截图。

本目录属于PLCWeave工具界面设计，不是客户PLC工程。客户程序、定制设计、接口构建档案、证据及交付继续放在各自 `project/<名称>/` 中。本轮没有实现软件、编写PLC程序、打开串口或新增监听端口。用户审核PRD后再开始开发。

可运行原型、设计规则、画面说明及实际截图在实现阶段随界面共同维护；无需从本轮文档启动服务。
