## 组件与绑定

| 组件 | 数据绑定 | 行为 |
| --- | --- | --- |
| X卡片 | X command / Effective X；辅助读硬件X | 仅仿真会话有效时可提交；目标与已生效分开显示 |
| AD行 | AD command / Effective AD；辅助读D8030–D8033 | 输入框、滑块、快捷值共享待应用值；提交后等PLC确认 |
| Y卡片 | Logical Y + FC01硬件Y | 两组只读状态；不可点击强制 |
| DA行 | Logical DA + FC03 D8050/D8051 | 两组只读值；未配置工程量纲就显示raw |
| 连接栏 | 本机串口配置及预检结果 | 不改PLC系统寄存器 |
| 联动开关 | Output enable request / actual | 显示PLC确认态；启用前提示当前将输出的值 |
| 状态栏/事件记录 | 事务、数据时间戳、请求确认 | 错误和过期不能被正常值覆盖隐藏 |

## 状态变体

- **未连接**：保留22点位布局，所有实际值为“—”；允许编辑未发送的目标输入。
- **已连接只读**：显示真实诊断；操作控件禁止提交，提供启用仿真入口。
- **仿真联动关**：开放输入操作，逻辑输出可变化，物理联动清晰标为关闭。
- **仿真联动开**：顶栏持续显示“物理输出联动”；两组输出值并列。
- **待确认**：输入卡片显示请求序号与待确认样式，不提前点亮生效灯。
- **错误/过期**：值标灰，带文字与时间；失去会话后不保留可操作外观。
- **停用未确认**：显示未确认原因与PLC看门狗设计时限，不显示“已安全停止”。
